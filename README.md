# rimon-fancade

Static, self-hosted copies of Fancade (and Mekorama) web builds used by the Rimon games site, embedded as iframes. No ads, no third-party requests (CSP enforced).

Games: speed-king, longcat, pool, roller, wall-of-doom, monster-match, roper, mekorama, recoil.

Fancade and Mekorama are by Martin Magni. Builds were taken from public Poki CDN exports; ad/tracking/sitelock code removed and the Poki SDK replaced by a local no-op stub.
